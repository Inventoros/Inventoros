# Inventoros 2.3.0

A small update with two inventory fixes, new currencies and dependency
security patches. It covers every change since 2.1.0.

## Fixes

- Generated SKUs handle non-ASCII letters. A category called "Könyvek" now
  produces `KÖN-000001` instead of `Kö-000001`, the `{name}` placeholder keeps
  accented letters instead of dropping them, and variant SKUs keep their
  parent's prefix. Location codes created during a product import follow the
  same rules. Existing SKUs are not changed.
  ([#328](https://github.com/Inventoros/Inventoros/issues/328))
- A minimum stock of 0 now means "no minimum". Items kept at 0 stock with a 0
  minimum, such as discontinued products still listed in a store, no longer
  appear in the Low Stock report, the dashboard low-stock tile, low-stock
  filters, exports or the products list warning. They only count once stock
  goes negative. Set a minimum of 1 to flag an item as soon as it runs out.
  Out-of-stock notifications and the `product.out_of_stock` webhook are
  unchanged. ([#330](https://github.com/Inventoros/Inventoros/issues/330))

## Currencies

- Added the Hungarian Forint (HUF) and the Russian Ruble (RUB).

## Security and maintenance

- Patched Symfony HttpFoundation, HttpKernel, Routing, Filesystem and Yaml
  advisories.
- The README shows receiving and order-to-ship demo recordings captured from
  the running application with fictional demo data.

## Upgrade

There are no database migrations in this release. Requirements are unchanged
from 2.1.0: PHP 8.4.1 or newer, MySQL 8.0+, PostgreSQL 13+ or SQLite for
development. Restart long-lived queue workers after updating.
