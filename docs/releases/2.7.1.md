# Inventoros 2.7.1

A fix release for 2.7.0, from the reviews of its dashboard, icon and
screenshot changes. There are no migrations and no new settings.

## Fixes

- **Search shortcut.** "/" opens global search only when no dialog is open
  and focus is not in a field. Before, it could open search behind an open
  dialog.
- **Product photos are cached.** Photo URLs already carried a version
  (`?v=`); the server now honours it. A request whose version matches the
  stored file is sent with `Cache-Control: private, max-age=31536000,
  immutable`, so the product list and dashboard stop downloading the same
  photos on every visit. Uploads always get a new file name, so a replaced
  photo has a new URL. Any other request keeps `private, no-store`. Photos
  stay behind sign-in and organisation checks.
- **Keyboard focus.** Breadcrumb links in the top bar show their full focus
  ring again.
- **Tables.** Validation errors and notes inside table cells wrap (receiving,
  purchase orders, returns). Product names, stock audit descriptions and
  warehouse descriptions get their width back and truncate with the full
  text on hover. The SKU line on the order form truncates the same way.
- **Breadcrumbs between 1024 and 1279px.** Only the shared "Workspace" or
  "Stock" root crumb is hidden at these widths, never a page's own first
  crumb.
- **Dashboard.** With a single column of panels, the main grid no longer
  leaves an empty second column.
- **Icons.** Empty states for Returns, Work Orders, Users, Roles and Plugins
  use the Inventoros icon set. Icons are hidden from screen readers only
  when they carry no label of their own.

## For plugin authors

The Inventoros icon components (`@/icons`) now keep an `aria-label`,
`aria-labelledby` or `title` you pass them visible to assistive technology,
and accept `absoluteStrokeWidth` (ignored) for drop-in use where Lucide
icons were used.

## Upgrading

Back up, then update to 2.7.1 the same way as for 2.7.0. Docker installs pull
the 2.7.1 image. See [UPGRADE.md](../../UPGRADE.md).
