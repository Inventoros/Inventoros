# Inventoros 2.5.0

This release adds pick lists, packing slips and receiving-bin selection to the
free core, lets the Linux installer run on older Bash, and bundles the interface
font so it loads everywhere. It includes every change since 2.4.0.

## Fulfilment and receiving

- Print an order pick list, and a price-free packing slip for each shipment,
  including partial and manual shipments. Both use the stored line and address
  data and never change stock, invoice numbers or shipment state.
- Choose the receiving bin for each line when you receive a purchase order, from
  the web form, REST, GraphQL or MCP. The choice applies to that receipt only:
  product locations and the purchase order's plan stay as they were, and partial
  deliveries keep their planned destinations.
- Receiving now rejects unavailable products or variants and rolls back the whole
  delivery, instead of reporting skipped lines as received.

See [purchase-order receiving](https://github.com/Inventoros/Inventoros/blob/v2.5.0/docs/features/purchase-order-receiving.md)
and [fulfilment documents](https://github.com/Inventoros/Inventoros/blob/v2.5.0/docs/features/fulfillment-documents.md).
([#338](https://github.com/Inventoros/Inventoros/pull/338))

## Installer

- The installer no longer requires Bash 4. It runs on Bash 3.2 and later, and CI
  now runs it end to end on Bash 3.2, 4.4 and 5.2. On macOS, which ships Bash
  3.2, you now get the installer's real message pointing you to Docker Desktop.
- It no longer stops on Linux systems whose `hostname` has no `-I` option, such
  as Alpine and Arch; the address falls back to `localhost`.

([#340](https://github.com/Inventoros/Inventoros/pull/340))

## Interface font

Bunny Fonts' stylesheet began pointing some regions at a CDN that the Content
Security Policy blocks, so those visitors saw the system font. Figtree is now
bundled with the app, and pages make no third-party font or stylesheet requests.
The policy allows fonts and styles only from the application's own origin.
([#341](https://github.com/Inventoros/Inventoros/pull/341))

## Security fixes

- Existing shipment rate requests, label purchases, dispatch, cancellations and
  web label downloads check the caller's ship-from warehouse assignments before
  any carrier call or change. ([#338](https://github.com/Inventoros/Inventoros/pull/338))

## README

The README is rebuilt around screenshots, a feature grid and the one-command

## Upgrade

There are no new database migrations since 2.4.0. Requirements remain PHP 8.4.1
or newer, MySQL 8.0+, PostgreSQL 13+, or SQLite for development. Back up the
database, `.env`, `APP_KEY`, uploads and installed plugins before upgrading.

For Docker, pull the 2.5.0 image and recreate the app, worker and scheduler with
the existing configuration and volumes. The Linux installer also accepts
`sudo bash install.sh --version 2.5.0`. Source and cPanel installations can use
their normal update process; source installs need `npm run build` for the
bundled font. Restart long-lived queue workers and clear/rebuild application
caches after updating. Run the normal migration command even though this release
adds none.
